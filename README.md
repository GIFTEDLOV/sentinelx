# SentinelX

SentinelX is a semantic release-security and governance layer for multiple GenLayer Intelligent Contracts. A protected target can only install a candidate after exact source binding, authenticated CI and security evidence, deterministic envelope validation, independent semantic review, finalized authorization, and exact post-install reconciliation.

Phase 1 targets GenLayer Studio-dev and Consensus v0.6 RC. It contains the contracts, deterministic direct tests, evidence and source utilities, preflight checks, and reviewer documentation. The frontend and deployment workflow are intentionally not implemented in this phase.

## Commands

```powershell
python -m pytest tests/direct -q
python scripts/preflight.py
```

The preflight script is fail-closed and only writes `artifacts/preflight-pass.json` after every deterministic gate succeeds. No deployment transaction or transaction evidence is generated by Phase 1.
